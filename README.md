# Teamy Storytelling

Public documentation and production materials for making explanatory videos with a reusable Codex cloud environment. The environment makes creative tools available; it does not require an orchestration CLI.

## Start here

- [Environment setup and provider status](docs/environment.md)
- [Storytelling workflow and delivery](docs/storytelling.md)
- [Production folders](projects/README.md)

The target saved environment is `storytelling-env`. Registration and provider smoke tests must be verified independently: a running task is not proof of a registered environment, and local renders are not cloud validation.
