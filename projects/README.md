# Productions

Use one directory per production, for example `projects/shapes-smoke/`. Common guidance stays under `docs/`.

A production may contain its brief, selected source files, public assets and attribution, provider-specific work, and review notes. Decide which finished media to commit deliberately; render caches and tool downloads stay out of Git. This initial layout can evolve without blocking environment setup.

No assets from other projects are approved for publication merely because this repository is public.

## Available productions

- [move_1_stack_direct orbit reconstruction](move1stack/README.md): pinned Motion Canvas / Three.js source, verified external-input recovery, first and source-cutout profiles, and fidelity limits. Acquired assets and generated media are excluded from Git.
