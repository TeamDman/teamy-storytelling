# Qualified rendering environment

This review was rendered with the already-installed Motion Canvas stack; no
provider, binary, credential or paid API was added. The repository-level
`docs/environment.md` describes provisioning. This file records the subset used
by the editable source archive, which does not bundle dependencies.

| Component | Qualified version / requirement |
|---|---|
| Motion Canvas core, 2d, UI, Vite plugin, FFmpeg plugin | 3.17.2 |
| Node.js | 24.19.0 |
| Vite | 5.4.21 |
| Playwright | 1.64.1 |
| Syntax highlighting | @wooorm/starry-night 1.7.0; installed Java, TOML, JSON TextMate grammars |
| Browser | Installed Chromium; set CHROMIUM to its executable path if needed |
| Video tools | FFmpeg / ffprobe 7.1.5 |
| Archives | Installed 7-Zip CLI (`7z`) |
| Contact sheets | Python 3 and installed Pillow |
| Fonts | DejaVu Sans and DejaVu Sans Mono |

The package manifest pins the direct JavaScript versions used. Link
`node_modules` to the qualified dependency tree. The Vite configuration resolves
that link for its local file allowlist. `scripts/runtime.cjs` stores the Motion
Canvas settings in the project's ignored `.runtime` directory. The renderer
uses an installed browser executable; it does not download one.

Run `node -r ./scripts/runtime.cjs node_modules/vite/bin/vite.js`, then the render
commands in README.md. The native exporter writes the MP4. The packaging script
only remuxes that stream into MKV, adds timeline-derived chapters, produces a
separate fast-start preview, and validates decoding. No frame animation is
generated by a second visual provider.

The official examples were read at pinned revision
`8ffefed144368d33de4b0e451894c718eb95d574`; this project adapts techniques to the
qualified newer runtime rather than running those examples as drop-in sources.

Historical Minecraft demonstration environments are separate and are documented
in commands.md inside the extras archive. A working animation runtime does not
prove that a local Minecraft manual demo has been prepared or verified.
